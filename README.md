# 🔓 Unlock TikTok – Free Browser Extension

Unblock TikTok at school, work, or abroad using a one-click proxy. Bypass restrictions and access content without limits.

## 🚀 Key Features

- **Unblock TikTok at School or Work** – Perfect for students or employees facing internet filters.
- **Bypass Country Restrictions** – Access TikTok even if it's banned or geo-restricted in your region.
- **Secure Proxy Technology** – Encrypted proxy servers ensure private and safe browsing.
- **Ultra-Fast Speed** – Smart server selection for a lag-free experience.
- **One-Click Simplicity** – Just install the extension and tap “Connect.” No tech skills needed.
- **Also Supports Douyin** – Watch Chinese TikTok content with no limitations.

## ✅ Get Started

1. Clone or download this repo
2. Load it as an unpacked extension in your browser (Chrome/Edge)
